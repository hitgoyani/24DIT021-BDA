## Aim
To perform exploratory and aggregative e-commerce sales data analysis using Apache Spark DataFrames and Spark SQL API.

---

## Problem Definition & Scenario
An e-commerce enterprise processes thousands of transactions daily. The management requires insights into product performance, regional revenues, customer spending distribution, and category profitability. Using Apache Spark DataFrames, this practical processes transaction datasets at scale, runs aggregations, handles null values, and demonstrates distributed DataFrame operations.

---

## Tasks
1. Initialize an optimized SparkSession with multi-threaded local execution.
2. Load structured e-commerce transactions into a Spark DataFrame with schema inference.
3. Perform exploratory data analysis (schema validation, row counting, summary statistics).
4. Analyze product category revenues and identify top-grossing product lines.
5. Identify top-spending customers and order volume distributions.
6. Formulate analytical queries using both DataFrame DSL (`select`, `groupBy`, `filter`) and Spark SQL views.
7. Export aggregated insights to structured output formats.
